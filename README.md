# Wunschkurs-Baukasten

Mitmach-Seite zur Vorstellung des Kurssystems der Oberstufe am BG/BRG Knittelfeld.

| Seite | Zweck |
|---|---|
| `index.html?k=4a` | Baukasten für die Schüler:innen (iPad), Klasse über den QR-Code |
| `galerie.html?k=4a` | Live-Wand für den Beamer, zeigt freigegebene Karten der Klasse |
| `freigabe.html` | Freigabe für Lehrkräfte (Anmeldung mit Supabase-Konto), CSV-Export |

Gespeichert wird in Supabase (Tabelle `kurskarten`, Region Frankfurt). Es werden keine Namen erfasst.
